# Hi 支持站

此仓库承载 Hi（4D4Y 客户端）的公开支持页面、隐私说明和 Issue 模板，将由 GitHub Pages 发布。

Hi（4D4Y 客户端）是面向 [4D4Y 论坛](https://www.4d4y.com/forum/) 的非官方 Apple 平台客户端。

## 本地预览

直接在浏览器打开 `index.html` 即可预览静态页面。发布工作流只上传 `index.html`、`privacy/` 与 `style.css`，不会上传仓库中的 Issue 模板或工作流配置。

## 公开反馈

请使用 GitHub Issues 反馈问题或建议。请勿发布密码、Cookie、登录验证码、私信内容、私人附件或其他个人信息。
